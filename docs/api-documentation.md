# API-Dokumentation

Swagger ist unter `/swagger` verfügbar.

- `GET /api/service-requests` – Liste mit Filtern und Pagination
- `GET /api/service-requests/{id}` – Detailansicht
- `POST /api/service-requests` – neue Anfrage
- `PUT /api/service-requests/{id}` – Anfrage ändern
- `DELETE /api/service-requests/{id}` – Soft Delete
- `GET /api/service-requests/dashboard` – KPI-Daten
- `GET /api/service-requests/buildings` – Gebäude und Räume
- `GET /health` – technischer Status
